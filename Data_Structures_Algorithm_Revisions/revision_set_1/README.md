This sub-repository contains Python solutions for the first set 1 of revision questions for the Data Structures Algorithm test

#### **1.Linked List Task**

* **Swap First and Last Nodes:** A method that swaps the very first node with the very last node in the list. It checks if the list has at least two nodes before swapping.  
* **Remove Duplicates:** A method for a sorted list that finds and removes extra copies of the same value so each number only appears once. 



#### **2.Stack \& Queue Tasks**

* **Copy Stack:** A method that makes a new, identical copy of a stack. It keeps the items in the same order without changing the original stack.  
* **Rotate Queue:** A method that moves items from the front of the queue to the back k times. If k is larger than the total number of items, it uses the remainder to decide how many times to move them. 



#### **3.Algorithm Tasks**

* **Binary Search Count:** A function that uses binary search to find a specific number in a sorted list and counts how many times that number appears.  
* **Modified Selection Sort:** A sorting function that puts a list in order and also counts exactly how many times it had to swap two items.  
* **Sum Even Numbers:** A simple function that looks at a list of numbers and adds only the even ones together to get a total.
