### **Content Overview**

#### **1. Linked List**

The linked list script includes the following features:  

* **Insert Before Value:** Adds a new value immediately before a specific target value in the list.  
* **Reverse List**: Reverses the order of all nodes in the list so the last node becomes the first.  



#### **2. Stacks and Queues**

These scripts demonstrate how to manage data using Last-In-First-Out (Stack) and First-In-First-Out (Queue) rules:  

* **Palindrome Check:** A method that checks if the items in a stack are the same when read forwards and backwards.  
* **Mirror Queue:** Takes the items in a queue, reverses them, and adds them to the end of the same queue.  



#### **3. Algorithms**

This section focuses on searching, sorting, and math operations on lists:  

* **Find Third Largest:** Finds and returns the third highest number in a list of unique numbers.  
* **Tracked Insertion Sort:** A sorting script that counts how many times it compares numbers and how many times it moves them.  Sum of Squares: A function that squares every number in a list and returns the total sum.
