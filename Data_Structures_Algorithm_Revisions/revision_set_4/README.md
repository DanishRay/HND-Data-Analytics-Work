### **Content Overview**



#### **1.Linked List**

* **Delete Nth Node:** Removes a node from a specific position in the list based on a 1-based index.  
* **Find Middle Value:** Identifies and returns the value of the node in the middle of the list.



#### **2.Stacks \& Queues**

**Reverse Stack:** Reverses all elements in a stack using only one extra temporary stack and standard stack operations.  

**Remove Every Second:** A method for queues that deletes every second item while keeping the rest in their original order.



#### **3.Algorithms**

* **Find Mode:** A function that searches a list to find the number that appears most frequently.  
* **Bubble Sort with Comparisons:** A modified sorting algorithm that tracks and displays the total number of comparisons made during the process.  
* **Even and Odd Difference:** Calculates the total sum of even numbers and the total sum of odd numbers, then returns the absolute difference between them.
