### **Content Overview**

#### **1.Linked List**

Modified the standard linked list to include :

* **Move Maximum to End:** Finds the node with the highest value and moves it to the final position in the list.  
* **Count Greater Than:** Accepts a specific value and returns a count of all nodes that have a higher value.



#### **2.Stack \& Queues**

* **Stack Duplicate Top:** Takes the top element of a stack and pushes an identical copy onto the top.
* **Queue Splitter:** Divides a single queue into two separate halves and returns them as new queues.



#### **3.Algorithms**

* **Find Missing Number:** Identifies the single missing integer in a sequence of consecutive numbers.  
* **Bubble Sort Pass Counter:** A modified bubble sort that tracks and displays the total number of passes completed to sort a list.  
* **Negative Number Filter:** A function that scans a list and returns a new list containing only zero or positive numbers.
