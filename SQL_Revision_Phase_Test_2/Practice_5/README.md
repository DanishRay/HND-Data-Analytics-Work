### **SQL Operations Covered In Revision: Alternative Set 4 Practice**



**Window Functions**

* **PARTITION BY ;-** Used to calculate per-customer transaction counts and category price averages
* **ORDER BY (Running Total**);- Used to calculate cumulative revenue growth over time





**Subqueries**

* **Scalar Subqueries ;-** Filtering products based on the global average stock quantity
* **NOT IN Subqueries ;-** Identifying inactive products that have never appeared in 'Completed' transaction





**Joins**

* **Inner Join ;-** Linking transaction items to products details and matching transactions to customer location data





**CASE Statements**

* **Transaction Priority ;-** Categorizing sales as 'High', 'Standard' or 'Low' based on the total amount
* **Inventory Urgency ;-** Labeling stock levels as 'Critical' or 'Stable' based on quantity thresholds





**Aggregations \& Grouping**

* **GROUP BY ;-** Collapsing data into specific buckets to find extreme values using MIN() and MAX()
