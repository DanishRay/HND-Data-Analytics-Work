### **HIGHLIGHTS SQL DEMONSTRATED**

* **Window Functions**: Utilizing OVER(PARTITION BY) and OVER(ORDER BY) to perform complex calculations (Running Totals, Categorical Averages) without losing row-level detail.



* **Relational Logic**: Implementing various JOIN types to unify disparate datasets across customers, transactions, and products.



* **Subqueries \& CTEs**: Using nested queries to filter data against dynamic benchmarks (e.g., finding transactions above the global average).



* **Conditional Logic**: Applying CASE WHEN statements to create data buckets and regional categories for reporting.



* **Aggregation**: Summarizing large datasets using GROUP BY and extreme value identification (MIN/MAX).





### **Business Use Cases**

* **Sales Performance:** Identifying products with zero sales to assist in inventory auditing.



* **Customer Segmentation**: Categorizing users by geographic region and spending tier.



* **Inventory Management:** Tracking running stock levels and monitoring category-specific stock limits.



* **Financial Reporting:** Calculating departmental budgets and transaction-level performance metrics.
