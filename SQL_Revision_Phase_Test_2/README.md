# **SQL PRACTICE : REVISION PHASE TEST 02**

This folder repositories contains SQL practices for a module Data Engineering, including the database schema and sample data that are given by the lecturers for the revision questions. These materials focus on SQL concepts such as window fuctions, subqueries and conditional logic.





### **DATABASE SCHEMA**

The database uses a retail-focused schema with four related tables:



* **customers:** Stores profile information like names, emails, and locations.



* **products:** Contains the inventory catalog, including pricing and current stock quantities.



* **transactions:** Records high-level order details, dates, and payment statuses.



* **transaction\_items:** A bridge table that lists specific products and quantities for every transaction.
