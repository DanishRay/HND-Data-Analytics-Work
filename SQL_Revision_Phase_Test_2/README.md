### **Overview**

The goal of this revision is to demonstrate proficiency in querying a relational database. The tasks include a wide range of SQL concepts, including ;-

* **Window Function** : Calculating running totals and partitioned averages
* **Subqueries :** Identifying specific data points like products above average price or inactive customers
