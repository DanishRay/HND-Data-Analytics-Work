### **Revision Set 4**

This repository sub-file contains Python scripts and study notes for the Revision Set 4. The scripts focusing on data cleaning, machine learning modeling, and data visualization using the pandas, scikit-learn and matplotlib libraries





#### **Question Structure**

1. **Sensor Logs (Question 1)**
* Files : script\_question\_1.ipynb, QUESTION 1 Notes.docx
* Task : Processing Sensor Logs
* Highlights Operation: 

  * Loading and inspecting CSV data
  * Handling missing numerical values using the mean
  * Filtering data based on specific string patterns
  * Categorizing data into Normal and Alert status





**2. Patient Records (Question 2)**

* Files : script\_question\_2.ipynb, QUESTION 2 Notes.docx
* Task : Building classification models to predict Patient Records
* Highlights Operation:

  * Data splitting using stratified sampling (80% train, 20% test)
  * Feature scaling using StandardScalar
  * Training and tuning K-Nearest Neighbors (KNN) and Decision Tree Models
  * Evaluating performance using Recall and F1-Score



**3. Olympic Medals (Question 3)**

* Files : script\_question\_3.ipynb, QUESTION 3 Notes.docx
* Task : Analyzing and visualizing sports performance data
* Highlights Operations : 

  * Removing duplicate entries for athletes
  * Creating scatter plots to show relationship between variables
  * Generating horizontal bar charts for top performers
  * Identifying the sport with the highest average gold medals per athlete





#### **Technical Requirements**

* **pandas**
* **scikit-learn**
* **matplotlib / seaborn**
